# سياراتُ TAXO ثلاثيّةُ الأبعاد — المصدرُ الواحد (أمرُ المالك ٢٠٢٦-١١-٢٠ الثامن)

**نماذجُ أصيلةٌ تُبنى بالمعادلات** (`cars.js`): أجسامٌ ملفوفةٌ بمقاطعَ فائقةِ الإهليلج، وزجاجٌ أسود، وعجلاتٌ بسيطة —
**لا طرازَ حقيقيّاً ولا شعارَ ولا شارة**، ولا مولِّدَ صور. وتُصوَّر بـthree.js r186 (رخصة MIT — استعمالٌ تجاريٌّ حرّ)
بإضاءة استوديو على خلفيّةٍ شفّافة.

**البرتقاليُّ على السيارة نفسِها**: شريطُ ضوءٍ أماميٌّ يلتفّ حول الأنف ووهجُه · خطٌّ رفيعٌ على الجانبين · المرايا · مراكزُ العجلات ·
زعنفةٌ صغيرةٌ على السقف. **خدمةُ النساء بلونها** (البرقوق نهاراً والورديّ ليلاً)، و«تاكسي المدينة» بلافتة سقفٍ بلا كتابة.

## التشغيل

```
cd design/cars-3d
npm i --no-save three@0.186.0 playwright   # مرّةً واحدة
node render.mjs                 # كلُّ الفئات: ثلاثةُ أرباع نهاراً وليلاً ١٢٨٠/٦٤٠/٣٢٠/١٦٠، والعلويّ بستّة ألوان ١٩٢/٩٦/٤٨ → out/
node render.mjs --quick economy # نهاراً وحده لفئةٍ واحدة (للتجريب)
node render-skins.mjs ../../backend/app/assets/skins/manifest.json out-skins   # متجرُ المركبات: العاديّة والمميّزة بلون كلٍّ منها
node shot.mjs board1.html BOARD-1-CARS.jpg     # اللوحة ١
node shot.mjs board2.html BOARD-2-WIDGETS.jpg 1900  # اللوحة ٢ (تحتاج glyphs.js من glyphsC.ts وUnbounded-800.ttf بجانبها)
```

## أين تُستعمل

| الموضع | الملفّات |
|---|---|
| أيقونةُ الفئة (الطلب، التتبّع، اللوحة) | `*/public/cars/<key>-34-<day|night>-<w>.webp` عبر `src/taxo2/cars.ts` و`Icon art` |
| علامةُ الخريطة العامّة (الراكب والكبتن) | `*/public/cars/<key>-top-white-96.webp` فوق السيارة المرسومة (تبقى إن لم تصل الصورة) |
| متجرُ المركبات — العاديّة والمميّزة | `backend/app/assets/skins/<key>-{store,map}.webp` — **المفتاحُ هو هو، فلا صفَّ في القاعدة يتغيّر** |
| الودجات (أندرويد/آيفون) | الصورُ نفسُها بمقاساتها |

**والنادرةُ والأسطوريّةُ يرفعها المالك من اللوحة ولا تمسّها هذه الأداة.** وأسماءُ الفئات وأسعارُها وقواعدُها لا تتغيّر.
