# أداة الحصول على رمز جهاز لإشعارات FCM

صفحةٌ واحدة تُخرج **رمز جهاز** من متصفحك، فتُختبر سلسلة الإشعارات كاملةً قبل
أن يوجد تطبيق راكبٍ أو كبتن يسجّل أجهزته. ليست جزءاً من المنتج ولا تُنشر:
أداةُ تطويرٍ تعيش هنا وحدها.

```bash
cd tools/fcm-token
cp config.local.example.js config.local.js   # مرةً واحدة: قيم مشروعك
python -m http.server 5174
# ثم افتح http://localhost:5174
```

`config.local.js` **مُستثنى من Git**: قيمه عامّةٌ بطبيعتها لكنها قيمُ بيئةٍ
بعينها. وغيابُه لا يعطّل الصفحة — تُلصق القيم في حقولها يدوياً (يظهر 404 في
وحدة تحكم المتصفح، وهو متوقَّع).

**المنفذ 5174**: مسموحٌ في `cors_origins` فيعمل زر «أرسل الإشعار»، و`5173`
يشغله مشروعٌ آخر على جهاز المطوّر. وعاملُ الخدمة لا يعمل على `file://` — فلا
تفتح الملف مباشرةً.

## ما تحتاجه من Firebase Console

1. **⚙️ Project settings ← General ← Your apps**: أنشئ تطبيق **ويب** (`</>`)
   إن لم يوجد، ثم انسخ كائن `firebaseConfig` إلى `config.local.js`.
2. **⚙️ Project settings ← Cloud Messaging ← Web Push certificates ←
   Generate key pair**: انسخ **مفتاح VAPID العام** إلى نفس الملف.

المفتاحان عامّان بطبيعتهما: `apiKey` ومفتاح VAPID يُنشران في كل تطبيق ويب.
**ما لا يُنشر أبداً** هو ملف حساب الخدمة (`secrets/`)، وهو ما تستعمله الخلفية
للإرسال — ولا علاقة له بهذه الصفحة.

## الخطوات في الصفحة

1. «اطلب الإذن واحصل على الرمز» → اسمح للإشعارات → انسخ الرمز.
2. في القسم الثاني: «سجّل الدخول واملأ التوكن» بحساب admin، ثم «أرسل الإشعار».

- **الصفحة مغلقة** → يعرض المتصفح الإشعار عبر `firebase-messaging-sw.js`.
- **الصفحة مفتوحة** → لا يعرضه المتصفح تلقائياً؛ يظهر في «ما يصل والصفحة
  مفتوحة» عبر `onMessage`. وهذا نفسه سببُ قاعدة **«لا Push لجهازٍ سوكته نشط»**
  في SPEC القسم 10.

## إن لم يصل الإشعار

| ما تراه | الغالب أنه |
|---|---|
| `invalid_token: true` | الرمز مقطوعٌ عند النسخ أو من مشروع آخر |
| `delivered: 1` بلا إشعار على الشاشة | الصفحة مفتوحة (انظر `onMessage`)، أو إشعارات المتصفح/النظام مكتومة |
| فشل الاتصال بالخلفية | الصفحة على منفذ غير مسموح في CORS، أو الخلفية متوقفة |
| `push_unavailable` (503) | عقد FCM غير مفعّل — `python -m scripts.seed` |

سجلُّ الخلفية يحمل نصَّ رفض Google حرفياً: `docker compose logs backend | grep FCM`.
