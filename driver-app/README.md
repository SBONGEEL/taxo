# taxo-driver-app — تطبيق الكبتن (المرحلة 10)

واجهةُ الكبتن: React 18 + Vite + TypeScript + Tailwind، عربيةٌ RTL، **وضعٌ
ليليٌّ افتراضي** (SPEC القسم 12.2).

## نظام التصميم

`tailwind.config.js` **منقولٌ حرفاً بحرف من `design/DESIGN.md` §6** — وذاك
الملف هو المصدر لا هذا. مفاتيح السلالم بالبكسل (`text-14.5`, `p-16`,
`rounded-13`) فالصنفُ يشهد على قيمته، ولا افتراضيَّ من Tailwind يبقى متاحاً:
`text-sm` أو `p-4` خطأُ بناءٍ لا انحرافٌ صامت.

## التشغيل

المنفذ **5174** (و5173 لتطبيق الراكب)، وهو أحد أصول CORS في
`settings.cors_origins` — تبديلُه يقطع كل نداء.

```bash
cd driver-app && npm install
npm run build   # فحصُ الأنواع كاملاً (tsc -b) ثم بناءُ إنتاج — البوابة قبل الالتزام
npm run lint    # tsc --noEmit وحده
npm run dev     # أو عبر الحاوية: docker compose up -d driver-app
```

لا مُشغّل اختباراتٍ هنا لنفس سبب تطبيق الراكب: لا منطقَ أعمالٍ في الواجهة —
التسعير والأرصدة وانتقالات الحالة كلها في الخلفية، والتطبيق يعرض ما يردّه
`api/`. و`npm run build` يفحص كل ملف.
