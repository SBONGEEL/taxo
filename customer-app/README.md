# TAXO — تطبيق الراكب (المرحلة 9)

PWA موبايل-أولاً على الـ API الجاهز. المرجع هو [SPEC.md](../SPEC.md) — القسم 11 للشاشات،
والقسم 10 لعقد الإشعارات والتتبع، والقسم 6 لصفحة دفع كليك.

## التشغيل

```bash
# مع بقية المنظومة (الخلفية على 8001، والتطبيق على 5173)
docker compose up -d --build

# أو محلياً بلا حاوية
npm install
npm run dev            # http://localhost:5173
npm run build          # فحص أنواع كامل ثم بناء الإنتاج
npm run lint           # tsc --noEmit وحده
```

**المنفذ 5173 ليس اختيارياً**: هو أحد أصول CORS المسموح بها في الخلفية
(`settings.cors_origins`)، وعليه يُبنى عنوان العودة من صفحة الدفع المستضافة
(`settings.card_return_url` → `/payments/card/return`).

## ما يعتمد عليه من الخلفية

لا يحمل هذا التطبيق مفتاحَ مزودٍ واحداً. كل ما يحتاجه يصله من `GET /config`:

| ما يُقرأ | لماذا |
|---|---|
| `auth.verification` | أيُّ تدفّق تحقّقٍ يُرسم: Firebase، أو رمزٌ نرسله، أو لا شيء |
| `countries[].features` | أيُّ قنوات دفعٍ وأيُّ أزرار محفظةٍ تُعرض في هذه الدولة |
| `providers.mapbox.public_token` | الخريطة والبحث بالعناوين |
| `providers.firebase_auth.*` | إعداد حزمة Firebase لإثبات الرقم |
| `providers.fcm.*` | إعداد الحزمة نفسها ومفتاح VAPID لرمز الجهاز |

فمفتاحٌ يُطفأ من صفحة العقود يختفي أثرُه من التطبيق بلا نشرٍ ولا بناء.

## قواعد لا تُخالَف في هذا المجلد

- **لا حساب مالي هنا.** المبالغ نصوصٌ كما وصلت (`NUMERIC(12,3)` يصل JSON نصّاً)، وتنسيقُها في
  `lib/utils.ts::formatMoney` نصّيٌّ بحت — تحويلها إلى `number` يمرّر المال بالفاصلة العائمة ولو
  للعرض. والسعر يأتي من `POST /rides/estimate`، ولا يُضرب كيلومترٌ في تعرفةٍ في أي ملف.
- **رسائل الخطأ تأتي من الخلفية كما هي** (`{code, message}` عربيةٌ جاهزة). الواجهة لا تترجم ولا
  تعيد الصياغة.
- **`device_id` واحدٌ في كل مكان**: يُولَّد مرة (`lib/device.ts`)، ويُرسل في `PUT /me/devices`،
  ويُفتح به المقبس. مقبسٌ بمعرّفٍ آخر يجعل الحدث يصل مرتين — على الشاشة ومن نظام التشغيل.
- **عامل الخدمة لا يخزّن `/api/` مؤقتاً.** رصيدٌ من كاشٍ عمرُه دقيقة كذبة.
- **العربية في كل نصٍّ يراه المستخدم وفي كل تعليق**، والمعرّفات إنجليزية — كما في الخلفية.

## الخريطة

`components/map/MapView.tsx` هو **الملف الوحيد** الذي يعرف واجهة `mapbox-gl`. يتولى ثلاثة أشياء:
سيارات الكباتن القريبين (بحركةٍ مُنعَّمة — القسم 10)، وموقع الكبتن المُسنَد أثناء الرحلة، ودبوسَي
الرحلة. والخط بينهما **مستقيمٌ متقطّع عمداً**: مسار الطريق يأتي من Directions، ونداؤها من الخلفية
حصراً، وما يصل الواجهة مسافةٌ ومدةٌ لا خطٌّ مرسوم.

الحزمة كبيرة (نحو 1.8 ميغابايت)، فهي في مقطعٍ منفصل والرئيسيةُ كسولة: من جاء ليسجّل دخوله لا
ينتظر محرّك خرائط.
