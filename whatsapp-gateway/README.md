# بوابةُ واتساب الذاتية

خدمةُ Node صغيرةٌ تشغّل [Baileys](https://github.com/WhiskeySockets/Baileys) على
**رقمٍ مخصّص**، وتعرض أربعةَ أبوابٍ لا تكلّمها إلا خلفيةُ TAXO.

القرارُ ومبرّراتُه وحرّاسُه في `SPEC.md` §15/أ، **وخطةُ الطوارئ بمددها في
`CLAUDE.md`**. وهذا الملفُّ للتشغيل وحده.

## الربط — متى تمسح الرمز

الرمزُ يظهر **لحظةَ إقلاع الحاوية وهي غيرُ مربوطة**، ويتجدّد من نفسه كلَّ
دقيقةٍ تقريباً حتى يُمسح. فامسحه متى شئت وهي تعمل — ولا حاجةَ لتوقيتٍ معيّن.

**من اللوحة** (الطريقةُ المعتادة): «عقود مزوّدي الخدمات» ← بطاقةُ «جلسة واتساب
الذاتية» في أعلى الصفحة. تعرض الحالَ ومربّعَ الرمز، وتستطلع كلَّ خمس ثوانٍ ما
دامت تنتظر — فتراها تتحوّل إلى «مرتبطة» بعد المسح بثوانٍ بلا أن تحدّث الصفحة.

**ومن الطرفية** (لتركيبٍ جديدٍ قبل أن تُفتح اللوحة):

```bash
docker compose exec whatsapp-gateway npm run link   # يطبع الرمز والحال
docker compose logs -f whatsapp-gateway             # الرمزُ يُطبع هنا أيضاً عند كل تجدّد
```

**وفي الهاتف**: واتساب ← الإعدادات ← **الأجهزة المرتبطة** ← ربط جهاز ← امسح.

يظهر بعدها في «الأجهزة المرتبطة» جهازٌ باسم **TAXO OTP** — وهو اسمٌ مقصود:
جهازٌ بلا اسمٍ مميَّز يُفصل بالخطأ يوماً.

## الأبواب

كلُّها تطلب `X-Gateway-Key` إلا `/health`.

| الباب | ماذا يفعل |
|---|---|
| `POST /send` | `{to, code, ttl_minutes}` — **ولا يقبل نصّاً**: النصُّ يُصاغ هنا |
| `GET /status` | حالُ الجلسة وعمقُ الطابور |
| `GET /qr` | رمزُ الربط الخام (تُحوّله اللوحةُ مربّعاً في المتصفح) |
| `POST /logout` | يفصل ويمحو — لربط رقمٍ آخر |
| `GET /health` | حياةُ العملية، بلا مفتاح، لفحص compose |

## المتغيّرات

| المتغيّر | الافتراضي | ماذا يعني |
|---|---|---|
| `WA_GATEWAY_KEY` | — | **إلزامي**: تخرج العمليةُ عند الإقلاع بدونه. مصدرُه `.env.local` |
| `WA_AUTH_DIR` | `/data/auth` | حالةُ المصادقة — **على حجمٍ دائم** |
| `WA_PORT` | `8080` | داخليٌّ فقط، ولا يُنشر في compose |
| `WA_MIN_GAP_MS` / `WA_MAX_GAP_MS` | `2000` / `6000` | مدى التباعد العشوائي بين رسالتين |
| `WA_MAX_WAIT_MS` | `25000` | أطولُ انتظارٍ في الطابور قبل الرفض الصريح |

**والسقوفُ ليست هنا**: سقفُ كلِّ رقمٍ وسقفُ الساعة في الخلفية على Redis
(`services/whatsapp/baileys.py`)، لأنهما **سياسةٌ** تُقاس وتُختبر وتنجو من إعادة
تشغيل — والتباعدُ هنا لأنه **إيقاعُ سلك**.

## حالةُ المصادقة والنسخُ الاحتياطي

`taxo_wa_auth:/data/auth` حجمٌ مسمّى، فإعادةُ بناء الصورة أو تشغيلها لا تُفقد
الجلسة. **وهي مفاتيحُ حسابٍ كاملة**: من نسخها ربط نفسَه مكانَنا — فتدخل النسخَ
الاحتياطي **مشفّرةً** كما يدخله مفتاحُ Fernet، ولا تدخل المستودعَ أبداً.

```bash
# نسخٌ احتياطي يدوي (والآليُّ يأتي مع خطة `design/BACKUP-AND-RESTORE.md`)
docker run --rm -v taxo-app_taxo_wa_auth:/data -v "$PWD":/out alpine \
  tar czf /out/wa-auth.tgz -C /data .
```
